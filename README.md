# marginalia

**Marginalia** is a small document Q&A service. You upload your own PDFs or
Markdown files, and you can ask questions in natural language — the system
retrieves the most relevant passages by similarity and answers with citations.
It is built as a reference architecture: a one-page design document, six
Architecture Decision Records, C4 container and component diagrams, and
sequence diagrams for the key flows accompany the working code.
